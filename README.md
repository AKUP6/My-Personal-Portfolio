## Personal Portfolio (React)

### Run locally

1. Install dependencies

```bash
npm install
```

2. Start the dev server

```bash
npm run dev
```

3. Open the URL printed in the terminal.

### Customize placeholders

- In `src/components/Welcome.jsx` update your name and headshot URL.
- In `src/components/Contact.jsx` update Name, Email, Phone in the contact details.
- In `src/components/Projects.jsx` update project titles, images, and descriptions.

### Tech

- React 18, Vite, vanilla CSS
